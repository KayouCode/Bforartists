LeStudio modeling primitives
============================

The ten object assets in LeStudio_Primitives.blend were generated with native
Bforartists/Blender mesh operators. Their thumbnail images were rendered with
the native Workbench renderer. Circle remains an edge-only mesh; its preview
uses a thin native torus solely to make the path legible in the shelf.

These assets supplement, and do not replace, the Bforartists asset library.
The original Bforartists and Blender license files remain in the distribution.
